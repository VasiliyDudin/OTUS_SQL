Мой план запроса (с учетом названий моей таблицы и колонок) -


EXPLAIN ANALYZE
SELECT 
    cl."First name", 
    cl."Last name", 
    cm."Name",
    COUNT(r."Id") AS rental_count, 
    MAX(r."Rent date") AS last_rental_date
FROM 
    public."Clients" as cl
JOIN 
    public."Orders" as r ON cl."Id" = r."Client_Id"
JOIN 
    public."Cinema" as cm ON r."Cinema_Id" = cm."Id"
WHERE 
    cm."Genre" = 'Боевик'
    AND r."Rent date" BETWEEN '2024-01-01' AND '2024-12-31'
GROUP BY 
    cl."First name",
    cl."Last name", 
    cm."Name"
ORDER BY 
    rental_count DESC, 
    last_rental_date DESC
LIMIT 10;

Результат плана запроса, прикрепляю в отдельном файле.

Узкие места запроса -
Полное сканирование Seq Scan по таблицам - "Orders", "Cinema", "Clients" нужно для используемых столбцов в условии запроса и в JOIN-ах сделать индексы
Неверный порядок - public."Cinema" as cm ON r."Cinema_Id" = cm."Id"
Исправить сам запрос

CREATE INDEX idx_orders_rent_date ON public."Orders" ("Rent date");

CREATE INDEX idx_orders_cinema_id ON public."Orders" ("Cinema_Id");

CREATE INDEX idx_cinema_genre ON public."Cinema" ("Genre");

CREATE INDEX idx_orders_client_id ON public."Orders" ("Client_Id");



EXPLAIN ANALYZE
SELECT 
    cl."First name", 
    cl."Last name", 
    cm."Name",
    COUNT(od."Id") AS rental_count, 
    MAX(od."Rent date") AS last_rental_date
FROM 
    public."Clients" as cl
JOIN 
    public."Orders" as od ON cl."Id" = od."Client_Id"
JOIN 
    public."Cinema" as cm ON cm."Id" = od."Cinema_Id"
WHERE 
    od."Rent date" BETWEEN '2024-01-01' AND '2024-12-31' 
    AND cm."Genre" = 'Боевик'
GROUP BY 
    cl."First name",
    cl."Last name", 
    cm."Name"
ORDER BY 
    rental_count DESC, 
    last_rental_date DESC
LIMIT 10;
